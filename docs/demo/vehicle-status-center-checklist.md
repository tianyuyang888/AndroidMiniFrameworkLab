## 断连与恢复

- [ ] Debug 包中点击“模拟服务断连”，远端 `:vehicle` 进程退出。
- [ ] 页面保留旧值但显示数据过期，并进入等待重连/连接中状态。
- [ ] 非主动断连后等待约 1 秒自动重连，重新收到首帧并恢复为已连接。
- [ ] 在可重复阻止 Service 绑定的测试条件下制造连续失败，确认最多自动尝试 3 次，之后显示手动重试。
- [ ] 点击手动重试后重新发起连接。

> “连续失败三次”通常需要临时停止/禁用被测包或使用可控故障环境，不能仅靠一次 Debug 进程死亡证明。不得为演示修改正式实现后忘记恢复。
